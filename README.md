# 🍔 Swiggy Data Analysis

## 📌 Overview
This project analyzes Swiggy restaurant data to understand pricing trends, customer ratings, and city-wise restaurant distribution using Python.

## 🎯 Objectives
- Clean and preprocess Swiggy data
- Analyze pricing and rating patterns
- Study restaurant distribution across cities
- Generate business insights

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
